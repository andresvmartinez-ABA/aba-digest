# Summary: LLM-Powered Real-Time Voice Agent for Task-Guided Practice in Serious Games for ASD The study aimed to develop a real-time voice guidance system that delivers step-by-step verbal support during game-based interventions for children with ASD, reducing the need for continuous therapist supervision during skill practice. The voice agent system has potential clinical utility for BCBAs and autism practitioners by enabling more autonomous practice of motor, cognitive, and social skills outside supervised clinical sessions, thereby increasing practice frequency and consistency while reducing scalability constraints associated with direct therapist prompting and correction.

Abstract

Children with Autism Spectrum Disorder (ASD) commonly need frequent prompting, correction, and encouragement from therapists during game based interventions that target motor, cognitive, and social skills, which can limit scalability and consistent practice outside clinical sessions. This paper proposes a real-time voice guidance system that integrates a speech driven agent with a Unity based serious game to deliver step-by-step verbal support during play. The agent communicates with the game through a WebSocket channel, continuously interprets gameplay events (such as level initiation, shape selection, object grab/release actions, and position updates), and produces concise guided prompts for children with ASD. The pipeline combines automatic speech recognition (ASR), a large language model (LLM) for instruction generation, and text-to-speech (TTS) synthesis with each response constrained to six words or fewer to reduce the linguistic load. In addition, coordinate information streamed from the game is used to generate directional cues without altering core game mechanics. The proposed voice agent layer supports more autonomous gameplay practice while reducing continuous therapist supervision.
